# depguard Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | :white_check_mark: |

## Reporting a vulnerability

depguard queries the public OSV.dev vulnerability database and never sends your
source code — only package names and versions (already public in a
requirements.txt). No secrets, credentials, or private identifiers are
transmitted.

If you find a bug in depguard itself, open an issue in this repository with:
- the depguard version,
- the requirements.txt scanned,
- the actual vs expected output.

Do not publish vulnerability details publicly until they have been addressed.
